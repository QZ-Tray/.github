# 🖥️ QZ Tray

QZ Tray is a **browser-to-printer bridge**. A web app connects over a **signed channel** and sends **raw** or **PDF** jobs to a local device.

## ✨ Key Features

- 🔐 **Signed connections** with certificates
- 🧾 **Raw printing** for receipts
- 📑 **PDF and image jobs**
- 🌍 **Cross-browser client**
- 🎚️ **Print option control**
- 🔔 **Callback events**
- 🖨️ **Device enumeration**
- 📄 **Silent printing** mode

## 🚀 Why Choose QZ Tray?

Browsers cannot reach serial or USB printers directly. The bridge closes that gap with a signature handshake, so a kiosk page can print without a print dialog.

Silent printing suits label and receipt flows where a prompt would stall the queue.

## 🧩 Quick Start

1. Install QZ Tray on the workstation.
2. Generate a certificate and key.
3. Sign the app requests.
4. Query the printer list.
5. Send a test job.
